# Ganpati Lifecare (GLC)

Modern medical & hospital supply distributor website for **Ganpati Lifecare**, Goluwala, Hanumangarh, Rajasthan.

## Stack

- Next.js 16 (App Router)
- Tailwind CSS 4
- Framer Motion
- TypeScript

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Brand assets (GLC cotton logo)

Official logo files live in `public/`:

- `logo.svg` — full horizontal logo (navbar, footer)
- `logo-mark.svg` — cotton + GLC mark (hero, loading, favicon source)
- `favicon.ico`, `favicon.png`, `favicon-16/32/48.png`, `apple-touch-icon.png`

**Replace with your uploaded logo:** overwrite `logo.svg` and `logo-mark.svg`, then run:

```bash
npm run generate:favicons
```

Brand colors: Orange `#F58220`, Green `#009245`, White `#FFFFFF`, Red-Orange `#E94B35`.
